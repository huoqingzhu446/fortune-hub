# 娱乐平台测算小程序改造计划

更新时间：2026-05-25
适用范围：`fortune-hub` 微信小程序审核版；兼顾抖音 / 快手同类娱乐平台审核口径。

## 1. 背景与目标

当前小程序已被审核指出存在“算卜算运势、算命、付费取名等平台未允许内容”。结合现有产品结构与平台通用审核规则，不能只做局部文案替换，必须把产品整体定位从“命理 / 运势工具”收口为“娱乐化趣味测试 / 自我观察 / 轻内容互动工具”。

本计划目标：

- 移除或下线所有高风险命理、运势、占卜、改运、付费解锁相关内容。
- 保留可过审的公开能力，如性格测评、情绪自检、呼吸、冥想、日记、记录、反馈等。
- 统一类目、文案、结果页、商业化、隐私合规口径。
- 输出一套提交审核前可逐项打勾的执行清单。

## 2. 红线结论

### 2.1 必须避免的产品定位

- 不能把产品呈现为“算命”“占卜”“运势预测”“改运工具”。
- 不能保留任何“付费查看命理结果”“付费解锁运势内容”“付费取名 / 改运 / 化解”的商业化路径。
- 不能出现“精准预测”“宿命结论”“灾祸判断”“健康 / 婚恋 / 财运必然结果”。

### 2.2 建议的审核版定位

- 趣味测试
- 性格分析
- 情绪观察
- 轻冥想 / 呼吸 / 日记
- 自我记录与成长陪伴

建议外显表述统一为：

- “趣味测试 / 性格分析 / 娱乐参考 / 自我观察”
- “结果仅供娱乐消遣和自我觉察参考”

## 3. 类目与主体改造

### 3.1 类目策略

- 微信：优先使用“生活服务 - 休闲娱乐”或“文化 - 传统文化”。
- 抖音：优先使用“工具 - 娱乐工具”。
- 快手：优先使用“娱乐 - 趣味测试”。

禁止：

- 选择“占卜”“算命”相关类目。
- 类目和实际功能不一致，例如挂“工具”但主体能力仍是付费命理。

### 3.2 主体与资质自查

- 使用企业主体。
- 营业执照经营范围覆盖文化、娱乐、信息服务、咨询服务等相关表述。
- ICP 备案齐全。
- 平台企业认证、对公验证完整。

## 4. 文案与命名改造

### 4.1 全局必加免责声明

建议统一使用：

`本小程序所有测试与解读结果仅供娱乐消遣和自我观察参考，不构成任何人生决策、投资、婚恋、医疗建议，请勿轻信或过度依赖。`

落位建议：

- 首页底部
- 结果页底部
- 报告页底部
- 关于页 / 隐私页
- 首次进入相关功能时的弹窗说明

### 4.2 全局禁用词黑名单

封建迷信类：

- 算命
- 占卜
- 改命
- 改运
- 消灾
- 化煞
- 转运
- 旺夫
- 克夫
- 天机
- 宿命
- 必发财
- 精准预测

医疗健康类：

- 治病
- 治癌
- 延寿
- 保胎
- 健康预测

绝对化承诺类：

- 100% 准
- 必准
- 一定
- 保证
- 注定

负向风险类：

- 死亡日期
- 凶兆
- 厄运
- 暴力指数
- 渣男
- 渣女
- 抑郁测试

### 4.3 推荐替换词

- “运势” → “状态趋势 / 今日状态 / 节奏提示”
- “占卜” → “趣味抽签 / 趣味测试 / 轻互动”
- “八字解读” → 建议审核版直接下线，不推荐仅改名保留
- “幸运签” → “今日一句话 / 今日提醒”
- “会员解锁” → 审核版直接移除

## 5. 内容与结果页改造

### 5.1 必须下线的功能

结合当前仓库现状，审核版建议直接下线：

- 星座
- 八字
- 占卜
- 幸运体系
- 命理海报 / 运势海报 / 幸运签分享
- 与上述功能相关的详情页、历史页、海报页、分享页

### 5.2 可保留的功能

- 性格测评
- 情绪自检
- 呼吸练习
- 冥想
- 日记
- 记录
- 收藏
- 设置 / 反馈 / 隐私 / 关于

### 5.3 结果页规范

- 结果必须多分支，不得呈现“唯一宿命结论”。
- 每个结果至少包含：
  - 3 到 5 条正向描述
  - 1 条中性提醒
  - 1 条免责声明
- 不得出现恐吓、诅咒、极端负向结论。
- 不得涉及生死、灾祸、重大疾病、法律风险、投资损益判断。

### 5.4 视觉元素禁用

- 符咒
- 铜钱卦象
- 香炉
- 纸钱
- 算命先生形象
- 强宗教仪式感素材

## 6. 商业化改造

### 6.1 当前策略

审核版建议：

- 全部下线付费内容
- 全部下线会员购买
- 全部下线订单支付
- 全部下线基于会员的解锁能力

原因：

- 微信明确不允许付费算命 / 付费看结果。
- 现阶段审核重点是先过审，不建议保留任何容易被误判的商业化壳子。

### 6.2 后续可选策略

如后续仍希望恢复商业化，仅建议围绕合规内容重建，例如：

- 冥想进阶课程
- 日记模板包
- 通用情绪报告
- 广告解锁更多非命理类内容

禁止恢复：

- 付费算命
- 付费运势
- 付费改运
- 付费取名
- 付费解锁命理报告

## 7. 隐私与数据合规改造

### 7.1 隐私协议要求

隐私协议中需明确：

- 收集项：昵称、头像、生日等可选字段
- 不收集：身份证、通讯录、地理位置、银行卡等敏感信息
- 不强制授权头像昵称
- 不以授权作为使用前提

### 7.2 数据侧要求

- 本地只存必要数据
- 不上传无必要的敏感字段
- 不诱导用户分享换结果
- 不通过私域、群、个人号导流继续付费测算

## 9. 分阶段执行计划

### 阶段 A：审核止血版

目标：快速移除所有高风险命理与付费内容，重新提审。

任务：

1. 下线星座、八字、占卜、幸运体系页面与入口。
2. 下线会员页、订单页、支付入口、解锁逻辑。
3. 统一改掉首页、探索、个人页、关于页的高风险文案。
4. 加上全局免责声明。
5. 更新小程序名称、简介、描述和审核说明。

验收标准：

- 小程序内找不到命理、运势、占卜、付费解锁入口。
- 审核截图只包含情绪、测评、呼吸、冥想、日记等内容。

### 阶段 B：内容合规版

目标：把保留功能包装成标准娱乐工具。

任务：

1. 重写结果页调性，全部偏正向、中性、轻量。
2. 去掉极端结论、宿命表达、恐吓式提示。
3. 梳理探索页内容分类，只保留合规项。
4. 检查分享海报与收藏文案。

验收标准：

- 结果页无绝对化承诺。
- 分享页和海报无违禁词、无命理意象。

### 阶段 C：商业化重建版

目标：审核通过后，再围绕合规功能设计新的商业化。

任务：

1. 重新设计非命理付费点。
2. 按平台差异设计广告解锁方案。
3. iOS / Android / 各平台口径统一。

验收标准：

- 不存在付费算命、付费运势、付费改运路径。

## 10. 提交前自检清单

### 10.1 类目与基础信息

- [ ] 类目为休闲娱乐 / 娱乐工具 / 趣味测试，不是占卜
- [ ] 名称、简介、描述无算命、占卜、改运、大师等词
- [ ] 企业主体、ICP、企业认证齐全

### 10.2 页面与功能

- [ ] 首页无星座、八字、占卜、幸运、付费入口
- [ ] 探索页无命理分类与内容
- [ ] 个人页无 VIP、会员、订单入口
- [ ] 报告页无解锁、会员引导
- [ ] 分享海报无命理内容

### 10.3 文案与内容

- [ ] 全局免责声明已显著展示
- [ ] 结果页无绝对化、宿命论、恐吓词
- [ ] 无渣男 / 渣女 / 暴力 / 抑郁类测试
- [ ] 无封建视觉元素

### 10.4 商业化与导流

- [ ] 无会员购买
- [ ] 无订单支付
- [ ] 无私域导流
- [ ] 无强制分享得结果
- [ ] 无二维码收款、线下一对一测算

### 10.5 隐私与授权

- [ ] 隐私政策完整
- [ ] 无强制授权头像昵称
- [ ] 不收集敏感隐私

## 11. 驳回原因与对应修复

### 11.1 驳回：存在封建迷信 / 命理测算

修复：

- 下线星座、八字、占卜、幸运体系
- 删除命理词
- 统一改成娱乐化描述

### 11.2 驳回：类目不符

修复：

- 调整为休闲娱乐 / 娱乐工具
- 同步修改产品介绍和页面结构

### 11.3 驳回：付费算命 / 付费看结果

修复：

- 立即下线会员与支付
- 去掉解锁逻辑
- 不保留“壳式付费页”

### 11.4 驳回：内容负向或不良引导

修复：

- 删除负向测试
- 结果改为正向 + 中性提醒

### 11.5 驳回：隐私不合规

修复：

- 补齐隐私协议
- 去掉强制授权
- 明确收集范围

## 12. 当前建议

对 `fortune-hub` 当前状态，建议优先执行：

1. 先完成“审核止血版”。
2. 先确保小程序公开端完全看不到命理与付费内容。
3. 等审核通过后，再讨论是否保留娱乐化趣味测试壳子，还是继续做情绪 / 自我成长方向收口。

现阶段不建议：

- 一边保留命理能力，一边只换文案试审。
- 一边保留会员体系，一边宣称“仅娱乐参考”。
- 通过隐藏入口、灰度、特殊参数方式绕审核。
